# Папка для фотографий альбома

Положи сюда свои файлы **с такими именами**:

| Файл | Куда попадёт |
|------|--------------|
| `main.jpg` | Главная фотка — **обложка** альбома (полностью на всю обложку). |
| `group-1.jpg` | Первая общая фотка — **редакторский разворот в самом начале** (после титула, перед содержанием). |
| `group-2.jpg` | Вторая общая фотка — **полнолистный портрет класса** в начале раздела «Класс». |
| `01.jpg` … `04.jpg` | Глава **«Сентябрь»** (4 кадра). |
| `05.jpg` … `10.jpg` | Глава **«Уроки»** (6 кадров). |
| `11.jpg` … `15.jpg` | Глава **«Перемены»** (5 кадров). |
| `16.jpg` … `23.jpg` | Глава **«Праздники»** (8 кадров). |
| `24.jpg` … `31.jpg` | Глава **«Поездки»** (8 кадров). |
| `32.jpg` … `43.jpg` | Глава **«Класс»** (12 кадров — две сетки 3×2 с портретами). |
| `44.jpg` … `49.jpg` | Глава **«Финал»** (6 кадров — последний звонок и пост). |

Итого **52 файла**: `main` + `group-1` + `group-2` + `01..49`.

## Когда фотки на месте — переключи режим

Открой `js/album.js` и в начале файла поменяй:

```js
const USE_PLACEHOLDERS = true;   // ← было
const USE_PLACEHOLDERS = false;  // ← должно стать, когда положил все файлы
```

Если поленишься — не страшно: пока конкретного файла нет, на странице
вместо него будет красивый затемнённый бокс с подписью `photo · placeholder`,
ничего не сломается.

## Рекомендации к фоткам

- **Формат:** `.jpg` (или `.jpeg`). PNG тоже работает, но весит больше.
- **Размер по длинной стороне:** 1600–2400 px. Меньше — будет мыло, больше —
  лишний вес страницы.
- **Ориентация:**
  - `main.jpg` — лучше **вертикальная** (3:4) или почти квадрат — ляжет на обложку.
  - `group-1.jpg`, `group-2.jpg` — **горизонтальные** (3:2 / 16:10) — это разворотные кадры.
  - `01..49.jpg` — может быть любая, шаблоны сами кропают по `object-fit: cover`.
- **Цветокор:** не обязателен — у альбома и без того тёмное оформление.

## Поменять подписи / порядок / разделы

Всё это лежит в одном файле — `js/album.js`, в массиве `SPREADS`.
Это декларативный список разворотов, его легко править без знания JS.
